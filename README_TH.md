# FaceSwap Lab — mobile web app

เว็บแอป PWA ภาษาไทยสำหรับเลือกภาพใบหน้าและคลิปบนมือถือ แล้วส่งไปทำ Face Swap ผ่าน Magic Hour API

## สถานะ

- หน้าจอมือถือ + ตัวอย่างภาพ/วิดีโอ: พร้อม
- Backend เชื่อม Magic Hour API: เตรียมไว้ใน `app.py`
- ยังทำงานจริงไม่ได้จนกว่าจะตั้ง `MAGIC_HOUR_API_KEY` ใน environment ของเซิร์ฟเวอร์
- ไฟล์ต้นฉบับจะถูกอัปโหลดไปยัง Magic Hour เพื่อประมวลผลเมื่อกดเริ่มงาน
- คีย์ API ต้องอยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามฝังใน JavaScript หรือส่งในแชต

## วิธีรันสำหรับทดสอบบนคอม

1. ติดตั้ง Python 3.11 หรือใหม่กว่า
2. ในโฟลเดอร์นี้ ติดตั้งแพ็กเกจ:

   ```bash
   pip install -r requirements.txt
   ```

3. กำหนดคีย์ใน environment (ไม่ต้องสร้างไฟล์ `.env` ที่แชร์สาธารณะ):

   **Windows PowerShell**
   ```powershell
   $env:MAGIC_HOUR_API_KEY="ใส่คีย์ของคุณ"
   uvicorn app:app --host 0.0.0.0 --port 8000
   ```

   **macOS / Linux**
   ```bash
   export MAGIC_HOUR_API_KEY="ใส่คีย์ของคุณ"
   uvicorn app:app --host 0.0.0.0 --port 8000
   ```

4. เปิด `http://localhost:8000` บนคอม หรือเปิด URL ของเซิร์ฟเวอร์ผ่าน Chrome บนมือถือ

## วางบนโฮสต์

ให้โฮสต์ที่รัน Python/FastAPI ได้และให้กำหนด environment variable `MAGIC_HOUR_API_KEY` ในส่วน Secrets/Environment Variables ของโฮสต์ จากนั้นตั้งคำสั่งเริ่มเป็น:

```bash
uvicorn app:app --host 0.0.0.0 --port $PORT
```

ตั้งค่า API key เป็น secret บนโฮสต์เท่านั้น ห้ามใช้ static hosting อย่างเดียว เพราะ API key ต้องเก็บใน backend ไม่ใช่ใน browser และอย่าเปิดบริการสาธารณะโดยไม่มีการป้องกันการใช้งาน

## ข้อจำกัดและค่าใช้จ่าย

- เป็นการสลับใบหน้า ไม่ใช่การเปลี่ยนทั้งตัว/ชุด/ฉาก
- หน้าเว็บจำกัดช่วงประมวลผลต่อคำขอไว้ 300 วินาทีเพื่อกันส่งผิดพลาด แต่ผู้ให้บริการอาจมีข้อจำกัดเพิ่มเติม; ทดลองคลิปสั้นก่อน
- เอกสาร Magic Hour ระบุ Face Swap Video คิดเครดิตตามความยาวคลิป (ตัวเลขที่แสดงในเอกสารราคาอาจเปลี่ยนได้) ตรวจยอดเครดิต/ราคาในบัญชีก่อนส่งงานยาว
- ใช้เฉพาะรูป/วิดีโอที่คุณมีสิทธิ์และได้รับความยินยอม
- โปรเจกต์นี้ไม่มีบัญชีผู้ใช้หรือระบบล็อกอิน; สำหรับการใช้งานบนอินเทอร์เน็ตจริงควรเพิ่มการยืนยันตัวตนหรือจำกัดผู้ใช้ในโฮสต์
